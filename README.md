# Fractal Visualizer

A Java desktop application for generating and exploring mathematical fractals. The application supports recursive fractal trees, Mandelbrot sets, and Julia sets with interactive controls, multithreaded rendering, and real-time visualization.

## Overview

Fractal Visualizer provides an interactive environment for exploring different fractal algorithms. Users can adjust rendering parameters, switch between fractal types, and generate high-resolution visualizations while rendering tasks execute concurrently in the background.

The project separates the graphical user interface from the rendering logic, allowing fractal generation to run asynchronously without blocking the application.

## Features

- Fractal Tree generation
- Mandelbrot set visualization
- Julia set visualization
- Interactive parameter controls
- Real-time rendering updates
- Multithreaded computation
- Rendering cancellation
- Dynamic viewport controls
- Smooth fractal coloring
- Responsive Swing interface

## Technologies

- Java
- Java Swing

## Concurrency

Rendering is performed using Java's concurrency framework.

The application utilizes:

- ExecutorService thread pools
- AtomicBoolean cancellation flags
- AtomicInteger task tracking
- BlockingQueue communication
- Background rendering
- Responsive UI updates
